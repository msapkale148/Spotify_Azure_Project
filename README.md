# Spotify_Azure_Project
Build a complete Data Engineering project from scratch using powerful tools like Azure Data Factory, Azure SQL DB, Azure Databricks, Unity Catalog, Delta Live Tables, Spark Streaming, PySpark, Databricks Asset Bundles, GitHub, and more. You’ll also dive into real-world concepts like Dimensional Data Modeling and Slowly Changing Dimensions (SCDs).

Azure Data Factory pipeline designed to perform incremental data loading, a common ETL (Extract, Transform, Load) process. Attached pipeline to web activity for pipeline status(Passed/Failed)
